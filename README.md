# Runo

Runo 是一个面向果园场景的离线视觉应用项目。目标是让用户用普通 Android 手机查看实时画面中的目标位置，之后逐步支持识别果实与病害，并能在定格画面上进一步了解识别结果。

项目同时用于学习从数据整理、模型训练到端侧推理的完整过程。识别结果应通过真实果园数据检验；果实检测与病害诊断是不同任务，不能混为一谈。

## 文件夹介绍：
- `android` 目录下存放的是安卓app
- `cpp` 目录下存放c++代码，本意是想实现**部署**，但是目前发现这个部署的活和c++是不是没什么关系？
- `docs` 存放各文件夹详细介绍，以及开发日志
- `python` 目录下就是主要的开发工作地点了，替换模型、训练推理等功能，希望后期都能上安卓

## 外部工程文件介绍
### .editorconfig
它告诉支持 EditorConfig 的编辑器：
- 使用 UTF-8 编码。
- 使用 LF 换行符。
- 文件末尾保留一个换行。
- Kotlin、C++、Python 统一使用四空格缩进。
这样你在 VS Code、Android Studio、Visual Studio 之间切换时，代码风格更容易保持一致。

### .gitattributes
它告诉 Git：
- 文本文件自动进行换行符规范化。
- Shell 脚本使用 LF。
- Windows 批处理文件使用 CRLF。
- 图片和 ONNX 模型按二进制文件处理。
尤其是你现在使用 Windows，同时可能在 WSL/Linux 中编译 C++，统一换行符可以减少跨平台问题。
