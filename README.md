# Runo

> Let me run!

Runo 是一个用于学习 **C++、计算机视觉与端侧 AI 部署** 的个人项目。

项目目标是开发一个能够在普通 Android 手机上**完全离线运行**的视觉识别应用，并逐步应用于真实果园场景。

## 项目目标

Runo 将从最基础的 C++ 摄像头程序开始，逐步实现：

- 使用 C++ / OpenCV 读取并显示摄像头画面
- 使用轻量级视觉模型进行实时目标检测
- 识别果实、叶片、害虫等目标
- 针对李子果园数据进行模型微调
- 识别果实品质、叶片病害和常见害虫
- 将模型部署到 Android 手机
- 在无网络环境下完成全部推理

## 技术路线

C++ / OpenCV  
↓  
实时摄像头采集  
↓  
轻量视觉模型  
↓  
ONNX / NCNN 等端侧推理框架  
↓  
Android NDK / JNI  
↓  
离线移动端视觉识别
