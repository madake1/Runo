# 数据文件

放置原始图片、标注、类别说明和训练/验证/测试划分文件。这里存放数据，读取和处理数据的 Python 代码放在 `datasets/`。

数据增加后，可以按数据集分别组织，例如：

```text
data/
└── leaf_disease/
    ├── raw/          # 保留原始图片与标注
    ├── processed/    # 可选：离线生成的裁剪或清洗数据
    └── splits/       # 训练、验证、测试的文件清单
```

保留原始数据，处理结果另存。同一叶片的连拍、同一原图的裁剪和增强版本应归入同一个划分，避免数据泄漏。训练时动态生成的增强图片通常不需要保存到磁盘。

数据文件默认不提交到 Git，本目录的 README 保留在版本管理中。
