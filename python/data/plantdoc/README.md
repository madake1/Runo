# PlantDoc 检测数据

通用作物叶片检测练习数据，不包含蜂糖李。官方框标记叶片目标，不是精细病斑边界。

- `raw/`：官方 TRAIN/TEST 图片、CSV、许可证、来源说明和下载报告。
- `annotations/`：转换后的 COCO train/val/test JSON 与清洗报告。
- `source/`：检索获取的官方仓库清单。

脚本和方案见 `../../datasets/plantdoc/README.md`。保留原图，不做去背景或离线增强。

本次下载 2,578 张图片，原始数据及标注约 995 MB。上游 CSV 引用但仓库缺失 3 张，另有 4 张 CSV 图片尺寸无效，均记录在报告。移除训练/测试像素重复图片 12 张；处理后训练 1,860、验证 466、测试 236 张，类别映射 29 类。测试集有两个类别没有真值，评估报告会明确列出。
